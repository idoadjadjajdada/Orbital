# Orbital notes

The project's notebook, kept in the repo so Claude can read and edit it in any session. Open this `notes/` folder as an Obsidian vault.

- [[Roadmap]]: what's next, in order
- [[Ideas]]: anything, unsorted
- [[Bugs]]: what looks wrong, and where
- [[Assets]]: the model packs and where they're used
- [[Built]]: what's in the game so far
- `Feedback/`: one note per round of requests
- `Worlds/`: a note per planet or moon

## Working with Claude
- "Work through [[Roadmap]]": items are done top to bottom and ticked off.
- "Fix what's in [[Bugs]]": each fix is noted under the bug with its commit.
- New ideas from chat go in [[Ideas]].
- Everything lands on `main` with the code.

## On iPhone
1. In **Working Copy**, clone `idoadjadjajdada/orbital` (sign in to GitHub first).
2. In **Obsidian**, open a vault from another app's folder and pick `orbital/notes` from Working Copy.
3. Before reading, **pull** in Working Copy. After writing, **commit and push** there.

Screenshots pasted into a note are saved under `notes/attachments/`, and Claude can see them.
