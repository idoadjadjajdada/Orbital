# Plans

A plan for each medium or large feature, written before any code: what it does, how, the edge cases and what the game does about them, the tests, and questions for you. Nothing is built until you've read it and answered its questions: say "go" (or what to change) in chat or in the notes app.

Each plan's first line says where it is: waiting for approval, approved, building (on which branch), or built.
