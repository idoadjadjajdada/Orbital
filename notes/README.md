# Orbital notes

The project's notebook, kept in the repo so Claude can read and edit it in any session. Open this `notes/` folder as an Obsidian vault.

- [Roadmap](Roadmap.md): what's next, in order
- [Ideas](Ideas.md): anything, unsorted
- [Bugs](Bugs.md): what looks wrong, and where
- [Assets](Assets.md): the model packs and where they're used
- [Built](Built.md): what's in the game so far
- [References](References.md): reference pictures, and what they were used for
- `Feedback/`: your messages word for word, by day, with their photos
- `Worlds/`: a note per planet or moon

## No computer needed
Tell Claude in chat: a bug, a feature, a photo. Claude keeps your message word for word in `Feedback/`, saves photos to `attachments/`, and files the bug or feature in [Bugs](Bugs.md) or [Roadmap](Roadmap.md). Read it all in the **GitHub app**: the repository, then `notes`. The notes and photos show there with no syncing.

## Working with Claude
- "Work through [Roadmap](Roadmap.md)": items are done top to bottom and ticked off.
- "Fix what's in [Bugs](Bugs.md)": each fix is noted under the bug with its commit.
- New ideas from chat go in [Ideas](Ideas.md).
- Everything lands on `main` with the code.

## In Obsidian on iPhone (optional)
1. In **Working Copy**, clone `idoadjadjajdada/orbital` (sign in to GitHub first).
2. In **Obsidian**, create a vault on the iPhone; in Working Copy, link the repository to that vault's folder.
3. Before reading, **pull** in Working Copy. After writing, **commit and push** there.

Screenshots pasted into a note are saved under `notes/attachments/`, and Claude can see them.
